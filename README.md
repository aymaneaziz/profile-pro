# ⚡ ProfilePro — PFE Internship @ SEOMANIAK

### An intelligent platform for generating CVs and building personalized portfolios

* Web platform for generating professional CVs and personalized portfolios with AI assistance.
* **Key Features:** Automated resume building, dynamic portfolio templates, and AI-powered content generation.
* **Tech Stack:** Symfony 7, React, MySQL, TailwindCSS
